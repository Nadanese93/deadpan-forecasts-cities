A one-line deadpan weather forecast for Copperleaf, a city that does not exist. In Copperleaf, lightning keeps a schedule: twelve bolts at 4:17 pm, and the council treats it as routine civic business.

## Run

```sh
python3 main.py
```

The program writes the forecast to `entry.txt` inside the output directory given by the `MAKEFUN_OUTPUT_DIR` environment variable, or `/output` when it is not set. The entry is a single line of 160 characters with no trailing newline.
